机制 MECHANISM

弹簧与 ARB 先合并为各轴轮端刚度，再形成前后侧倾刚度分配，把横向载荷转移分到左右轮。纵向 G 通过质心高度与轴距在前后轴之间搬移垂直载荷；驱动力全部分配给后轴，制动力近似按前 60% / 后 40% 分配。每只轮胎用 AC 的载荷敏感幂律，从实际 Fz 得到 μ 与 Fy,max；把每轴侧向与纵向需求合成为合力，与该轴总抓地力比较即得联合利用率。 

Kφ = (k_spring + k_ARB) · t² / 2
share_F = Kφ_F / (Kφ_F + Kφ_R)
ΔFz_lat,F = share_F · m · a_y · h / t_F
ΔFz_long  = m · a_x · h / L
k = 1 − LS_EXPY
μ(Fz) = μ_ref · (Fz / FZ0)^(−k)
Fy,max = μ(Fz) · Fz
Fgrip,axle = Σ Fy,max
F_res,axle = √(Fy,demand² + Fx,demand²)
U = F_res,axle / Fgrip,axle

边界与假设 LIMITS

  • 稳态、平地；G-G 输入允许侧向 + 纵向组合；不含瞬态、差速器锁止和空气动力学。
  • 仅模拟底盘重心 / 载荷转移与载荷敏感 μ(Fz)；忽略轮胎滑移角、滑移率、侧偏刚度及轮胎松弛对 μ 的影响。
  • 轮胎曲线使用 AC 解包的 FZ0 / DY_REF / LS_EXPY；WIDTH 不进入 μ(Fz)。未建模 Camber / Toe / 温度 / 压力。
  • AC 胶料参数只读；自定义模式可改 μ_ref / k，FZ0 继承上一次 AC 胶料。
  • 驱动力 100% 后轴；制动力按固定 60% 前 / 40% 后 近似。纵向力分配与滑移无关，但仍决定每轴 Fx 和联合利用率。未建模 EBD 与制动偏置变化。
  • 3D 底盘按 AC 的 STRUT / DWB 架构、GT86 轴距/轮距与轮端刚度做简化机构示意。
  • ARB 的 AC 原文件注释与 CSP 文档在单位表述上存在差异；按等效轮端 N/m 读取。
