机制 MECHANISM

轮上弹簧率与防倾杆轮率先合并为每侧悬挂轮率，再与轮胎弹簧率串联成接地轮率，由它形成前后侧倾刚度分配并把横向载荷转移分到左右轮。纵向 G 通过质心高度与轴距在前后轴之间搬移垂直载荷；驱动力按所选的 RWD / FWD / AWD 分配，制动力默认取所选车型 AC brakes.ini 的前轴占比，也可在调校台调整。每只轮胎用 AC 的载荷敏感幂律，从实际 Fz 得到 μ 与 Fy,max；把每轴侧向与纵向需求合成为合力，与该轴总抓地力比较即得联合利用率。 

lateralG > 0 = 右转 · lateralG < 0 = 左转
k_susp,axle = k_spring + k_ARB
k_ground,axle = 1 / (1 / k_susp,axle + 1 / k_tyre,axle)
Kφ,axle = k_ground,axle · t² / 2
share_F = Kφ_F / (Kφ_F + Kφ_R)
ΔFz_lat,F = share_F · m · |a_y| · h / t_F   (每只外侧轮 +，内侧轮 −)
ΔFz_long = m · a_x · h / L
brake_F = 当前车型 brakes.ini FRONT_SHARE
drive_F / drive_R = RWD 0/100 · FWD 100/0 · AWD 50/50
k_F / k_R = 1 − LS_EXPY,F / 1 − LS_EXPY,R
μ_F(Fz) = μ_ref,F · (Fz / FZ0,F)^(−k_F)
μ_R(Fz) = μ_ref,R · (Fz / FZ0,R)^(−k_R)
Fy,max = μ_axle(Fz) · Fz
Fgrip,axle = Σ Fy,max
F_res,axle = √(Fy,demand² + Fx,demand²)
U = F_res,axle / Fgrip,axle

边界与假设 LIMITS

  • 稳态、平地；G-G 输入允许侧向 + 纵向组合（正侧向 = 右转）；不含瞬态、差速器锁止和空气动力学。
  • 仅模拟底盘重心 / 载荷转移与载荷敏感 μ(Fz)；忽略轮胎滑移角、滑移率、侧偏刚度及轮胎松弛对 μ 的影响。
  • 轮胎曲线使用 AC 解包的 FZ0 / DY_REF / LS_EXPY；所载 19 款车的轮胎段均无 DY_CURVE，因此使用上式幂律；FRONT / REAR 分别计算，WIDTH 不进入 μ(Fz)。未建模 Camber / Toe / 温度 / 压力。
  • AC 胶料参数只读；自定义模式可改 μ_ref / k 和前后轮胎弹簧率，FZ0 继承上一次 AC 胶料。轮胎垂向 RATE 与悬挂轮率按串联近似参与侧倾刚度。
  • 内侧车轮离地时，按轴荷守恒截断内外轮载荷；超出线性范围后未把剩余侧倾力矩重新分配给另一轴。
  • 制动默认取所选车型 brakes.ini（均 COCKPIT_ADJUSTABLE = 0），页内可调；驱动默认取所选车型 drivetrain.ini，可选 FWD / AWD（AWD 固定 50/50）。纵向力分配与滑移无关，但仍决定每轴 Fx 和联合利用率。未建模 EBD。
  • 3D 底盘的轴距、轮距、悬架架构与硬点按所选车型数据绘制；AC 数据缺少减震器上支点时由几何推导，车身与防倾杆外形为示意。
  • 防倾杆轮率的 AC 原文件注释与 CSP 文档在单位表述上存在差异；所载车型均按轮端等效 N/m 读取。
